META NEWS AUTOMATION APP

Privacy Policy

Effective November 23, 2026

This policy describes information handled by the Himal Samachar news automation and this static legal-information website. The app is an editorial publishing tool; it does not provide reader accounts or Facebook Login.

What the automation processes

The only active news source is Radio Nepal’s official public RSS feed. The automation reads article titles, dates, links, and available text to select a story and draft an original Nepali summary. It does not request Facebook follower profiles, comments, or Messenger conversations.

The Meta integration checks the Himal Samachar Page identity and posting capability, publishes a text summary with source attribution and a canonical source link, then reads the resulting post back to verify its ID, Page identity, message, and permalink.

Operational records

Supabase stores story and publishing history used for duplicate prevention and verification. Fields can include a story fingerprint, source title, canonical and source URLs, generated headline and summary, source count, status, Meta post ID, and creation and publication times.

Correction and update records can include a key, original post ID and URL, notice text, source URL, status, new Meta post ID, and timestamps. A short-lived lock record prevents overlapping runs.

The app has no configured automatic deletion schedule for these records. They remain in the database until an authorized administrator removes them or applicable service retention processes apply. This project specifies no fixed retention period.

Service providers

  • Radio Nepal supplies the public RSS feed and linked source material.
  • Google Gemini API receives source text and article metadata needed to draft and validate summaries.
  • Supabase runs the server-side automation and stores operational records.
  • Meta verifies the Page, receives post text and source links, and returns post data for verification.
  • GitHub Pages hosts this static site and may process technical request information under GitHub’s policies.

Credentials are kept in server-side environment or secret storage. They are not included in this site or in public post messages.

Public content and this website

Published summaries and links are visible on the Himal Samachar Facebook Page. Meta and source publishers handle their own copies and service data under their respective policies. This app does not control those records.

This website’s source contains static HTML and CSS only. It has no login, analytics scripts, advertising pixels, or visitor-submission form. Hosting providers may still process routine connection data.

Questions and requests

To ask about information associated with a person or a specific Page post, send a private message to the Himal Samachar Facebook Page. Include the source article URL or Page-post permalink and describe what you want reviewed. Do not send passwords, access tokens, or unnecessary sensitive documents.

The app has no self-service deletion endpoint. Requests are reviewed manually. Removing an app database record does not itself remove public Page posts or records held by Meta, Google, Supabase, GitHub, or a source publisher; each service has its own processes.
